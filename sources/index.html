SECTION 01

نورم-۲ برداری
نورم اقلیدسی / Euclidean Norm

1-1 تعریف

تعریف Definition

برای بردار x = (x1, x2, … , xn)T ∈ ℂn ، نورم-۲ برداری (که به نورم اقلیدسی معروف است) بر حسب ضرب داخلی به صورت زیر تعریف می‌شود:

(۱-۱) ‖x‖2 = √⟨x, x⟩ = √xHx = √nΣi=1 |xi|2

و برای بردارهای حقیقی x ∈ ℝn:

(۱-۲) ‖x‖2 = √xTx = √x12 + x22 + … + xn2
SECTION 01 · 02

اثبات نورم بودن ‖x‖2

برای اینکه یک تابع ‖·‖ : V → ℝ یک نورم باشد، باید سه اصل زیر را ارضا کند. در ادامه اثبات این سه اصل برای نورم-۲ ارائه می‌شود:

AXIOM 01 اصل اول: مثبت بودن و ناصفر بودن Non-negativity & Definiteness

حکم: ‖x‖2 ≥ 0 برای هر x ∈ ℂn، و ‖x‖2 = 0 ⟺ x = 0.

اثبات Proof

چون برای هر عدد مختلط xi داریم |xi| ≥ 0، پس مجموع قدر مطلقِ مربعِ درایه‌ها نیز غیرمنفی است:

nΣi=1 |xi|2 ≥ 0 ⟹ ‖x‖2 = √nΣi=1|xi|2 ≥ 0

همچنین:

‖x‖2 = 0 ⟺ √nΣi=1|xi|2 = 0 ⟺ nΣi=1|xi|2 = 0

از آنجا که تمام جملات |xi|2 غیرمنفی هستند، مجموع آن‌ها تنها زمانی صفر می‌شود که تک‌تک جملات صفر باشند:

|x1|2 = |x2|2 = … = |xn|2 = 0 ⟺ x1 = x2 = … = xn = 0 ⟺ x = 0 ∎
AXIOM 02 اصل دوم: همگن‌پذیری مطلق Absolute Homogeneity

حکم: برای هر اسکالر α ∈ ℂ و هر بردار x ∈ ℂn داریم ‖αx‖2 = |α|‖x‖2.

اثبات Proof

درایه‌های بردار αx به صورت (αx1, αx2, … , αxn)T هستند:

‖αx‖2 = √nΣi=1|αxi|2 = √nΣi=1|α|2|xi|2

چون |α|2 یک فاکتور مشترک ثابت است، آن را از سیگما خارج می‌کنیم:

‖αx‖2 = √|α|2 nΣi=1|xi|2 = √|α|2 · √nΣi=1|xi|2 = |α|‖x‖2 ∎
AXIOM 03 اصل سوم: نامساوی مثلث Triangle Inequality · Minkowski

حکم: برای هر دو بردار x, y ∈ ℂn داریم ‖x + y‖2 ≤ ‖x‖2 + ‖y‖2.

اثبات Proof

ابتدا از مربع نورم-۲ شروع می‌کنیم:

‖x+y‖22 = ⟨x+y, x+y⟩ = ⟨x, x⟩ + ⟨x, y⟩ + ⟨y, x⟩ + ⟨y, y⟩

می‌دانیم ⟨y, x⟩ = ⟨x, y⟩ و برای هر عدد مختلط z داریم z + z̄ = 2 Re(z):

‖x+y‖22 = ‖x‖22 + 2 Re(⟨x, y⟩) + ‖y‖22

از آنجا که برای هر عدد مختلط Re(z) ≤ |z| است، و با به‌کارگیری نامساوی کوشی-شوارتس (|⟨x, y⟩| ≤ ‖x‖2‖y‖2):

‖x+y‖22 ≤ ‖x‖22 + 2|⟨x, y⟩| + ‖y‖22 ≤ ‖x‖22 + 2‖x‖2‖y‖2 + ‖y‖22

سمت راست عبارت بالا یک مربع کامل است:

‖x+y‖22 ≤ (‖x‖2 + ‖y‖2)2

با گرفتن جذر از طرفین (چون طرفین مثبت هستند):

‖x+y‖2 ≤ ‖x‖2 + ‖y‖2 ∎
SECTION 01 · 03

مثال‌های عددی برای نورم-۲ برداری

EXAMPLE 01 بردار حقیقی

بردار x = (3, −4, 12)T ∈ ℝ3 را در نظر بگیرید:

  1. مربع هر درایه را حساب کنید: 32 = 9، (−4)2 = 16، 122 = 144
  2. مجموع مربع‌ها: 9 + 16 + 144 = 169
  3. گرفتن جذر: √169 = 13
‖x‖2 = √32 + (−4)2 + 122 = √9 + 16 + 144 = √169 = 13
پاسخ:‖x‖2 = 13
EXAMPLE 02 بردار مختلط

بردار y = (1+i, 2−i, 3)T ∈ ℂ3 را در نظر بگیرید:

  • |1+i|2 = 12 + 12 = 2
  • |2−i|2 = 22 + (−1)2 = 5
  • |3|2 = 9
‖y‖2 = √2 + 5 + 9 = √16 = 4
پاسخ:‖y‖2 = 4

SECTION 02

نورم-۲ ماتریسی
نورم طیفی / Spectral Matrix Norm

2-1 تعریف

تعریف Definition

برای ماتریس A ∈ ℂm×n، نورم-۲ ماتریسی (که نورم طیفی نیز نامیده می‌شود) به عنوان نورمِ طبیعیِ القاشده از نورم-۲ برداری تعریف می‌شود:

(۲-۱) ‖A‖2 = maxx ≠ 0 ‖Ax‖2‖x‖2 = max‖x‖2=1 ‖Ax‖2

فرمول محاسباتی:

(۲-۲) ‖A‖2 = √ρ(AHA)

که در آن ρ(AHA) شعاع طیفی (بزرگ‌ترین مقدار ویژه) ماتریس AHA است.

2-2 ویژگی‌های کلیدی و اثبات‌ها

P.01 اگر A هرمیتی باشد (AH = A)، آنگاه ‖A‖2 = ρ(A)
اثبات Proof

اگر AH = A باشد، آنگاه AHA = A2. اگر مقادیر ویژهٔ A برابر λi باشند، مقادیر ویژهٔ A2 برابر λi2 خواهند بود. بنابراین:

ρ(AHA) = ρ(A2) = maxi |λi2| = ( maxi |λi|)2 = (ρ(A))2

با جایگذاری در فرمول نورم طیفی:

‖A‖2 = √(ρ(A))2 = ρ(A) ∎
P.02 ناوردایی تحت ضرب یکانی (Unitary Invariance)

برای هر دو ماتریس یکانی U و V داریم:

‖U A V‖2 = ‖A‖2

یعنی ضرب در ماتریس‌های یکانی، نورم طیفی را تغییر نمی‌دهد؛ از این رو مقدارهای منفرد A (از تجزیهٔ SVD) کاملاً ‖A‖2 را تعیین می‌کنند.

SECTION 02 · 03

مثال‌های عددی برای نورم-۲ ماتریسی

EXAMPLE 03 ماتریس متقارن

ماتریس متقارن A = 4114 را در نظر بگیرید.

  1. محاسبهٔ مقادیر ویژه:
    det(A − λI) = (4−λ)2 − 1 = 0 ⟹ 4 − λ = ±1 ⟹ λ1 = 5,   λ2 = 3
  2. شعاع طیفی: ρ(A) = max{5, 3} = 5
  3. چون A متقارن حقیقی است (AT = A)، نورم طیفی آن برابر شعاع طیفی است.
‖A‖2 = ρ(A) = 5
پاسخ:‖A‖2 = 5
EXAMPLE 04 ماتریس عمومی غیرمتقارن

ماتریس B = 0300 را در نظر بگیرید.

  1. تشکیل ماتریس BTB:
    BTB = 0030 0300 = 0009
  2. مقادیر ویژهٔ BTB عبارتند از λ1 = 0 و λ2 = 9.
  3. شعاع طیفی: ρ(BTB) = 9
  4. نورم طیفی:
    ‖B‖2 = √ρ(BTB) = √9 = 3
پاسخ:‖B‖2 = 3

یادداشت Remark

برای هر بردار x ∈ ℂn نامساوی‌های زیر میان نورم‌ها برقرار است:

‖x‖∞ ≤ ‖x‖2 ≤ ‖x‖1 ≤ √n‖x‖2

این نامساوی‌ها نشان می‌دهند که همهٔ نورم‌ها در فضا‌های بعدِ متناهی هم‌ارزند؛ اما مقدار عددی آن‌ها متفاوت است و انتخاب نورم مناسب در تحلیل خطا و پایداری عددی اهمیت دارد.
